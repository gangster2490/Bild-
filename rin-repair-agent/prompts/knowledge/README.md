# База знаний RIN Repair Agent

Домен: ремонт **колясок** (в т.ч. с электроприводом) и **детских автокресел**.

Файлы в этой папке копируются в APK как `assets/knowledge/` и подмешиваются
в системный контекст AI при анализе фотографий.

| Файл | Содержание |
|------|------------|
| `index.json` | Каталог разделов и ключевые слова для отбора |
| `safety.txt` | Общие правила безопасности |
| `tools.txt` | Инструменты и крепёж |
| `strollers.txt` | Коляски, приводы, моторы, ремни (ориентир eGazelle) |
| `car_seats.txt` | Автокресла, ISOFIX, harness, обивка |
| `rin_style.txt` | Стиль текста RIN |

Правило: база знаний помогает узнавать узлы и формулировать шаги,
но **не отменяет** запрет придумывать то, чего нет на фото.
