# RIN Repair Agent

Android-приложение и backend для создания ремонтных инструкций RIN по фотографиям.

Пользователь снимает ремонт камерой (или выбирает фото / ZIP). AI анализирует каждое фото и формирует пошаговую инструкцию для новичка. На выходе:

- `RIN_Repair_Instruction_RU.pptx`
- `RIN_Repair_Instruction_EN.pptx`
- `RIN_Repair_Instruction_RU.pdf`
- `RIN_Repair_Instruction_EN.pdf`

**RIN-шаблон не встроен в APK.** Его нужно загрузить после установки через Storage Access Framework.

## Структура

```
rin-repair-agent/
├── android/     # Kotlin + Jetpack Compose приложение
├── backend/     # Node.js сервер (AI, PPTX, PDF)
├── prompts/     # Промпты для AI-анализа
├── output/      # Локальные результаты генерации backend
└── README.md
```

## 1. Как открыть проект

1. Откройте папку `rin-repair-agent/android` в Android Studio (File → Open).
2. Дождитесь синхронизации Gradle.
3. Backend открывается отдельно: `rin-repair-agent/backend`.

## 2. Как запустить backend

```bash
cd rin-repair-agent/backend
npm install
npm start
```

Сервер слушает `http://0.0.2.2` эквивалент для эмулятора:

- эмулятор Android: `http://10.0.2.2:3000` (значение по умолчанию в приложении)
- реальный телефон: `http://<IP-вашего-компьютера>:3000` или HTTPS-адрес

Проверка:

```bash
curl http://localhost:3000/health
```

## 3. Как собрать APK

```bash
cd rin-repair-agent/android
./gradlew assembleDebug
```

Готовый файл:

```
rin-repair-agent/android/app/build/outputs/apk/debug/app-debug.apk
```

Release:

```bash
./gradlew assembleRelease
```

## 4. Как установить APK на телефон

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Или скопируйте `app-debug.apk` на телефон и установите вручную (разрешите установку из неизвестных источников).

## 5. Как ввести API-ключ

При первом запуске:

1. Введите API-ключ.
2. Выберите провайдера: **OpenAI** или **Gemini**.
3. Нажмите **Проверить ключ**.
4. Нажмите **Сохранить**.

Ключ хранится только через **Android Keystore** + EncryptedSharedPreferences:

- не в открытом виде;
- не в APK;
- не в логах;
- на экране видны только последние 4 символа.

В настройках доступны изменение, удаление ключа и проверка подключения к серверу.

## 6. Как добавить RIN-шаблон

1. На главном экране нажмите **Добавить RIN-шаблон**.
2. Выберите файл через системный проводник (`ACTION_OPEN_DOCUMENT`).
3. Разрешены: **PPTX**, ZIP, JSON, PDF. Основной шаблон — `.pptx`.
4. Шаблон копируется во внутреннее хранилище и сохраняется между запусками.
5. Доступны **Заменить шаблон** и **Удалить шаблон** (с подтверждением).

Пока шаблон не добавлен, на главном экране показывается:

> Сначала добавьте RIN-шаблон PowerPoint.

## 7. Как сделать первый ремонт

1. Запустите backend и укажите адрес сервера в настройках.
2. Добавьте RIN-шаблон.
3. Нажмите **Новый ремонт**.
4. Заполните название, изделие/модель, язык результата (RU / EN / оба).
5. Добавьте фото:
   - камера (CameraX / TakePicture);
   - галерея (Android Photo Picker);
   - ZIP-архив.
6. После каждого фото приложение сохраняет его локально, показывает миниатюру и отправляет на AI-анализ.
7. Перейдите к экрану **Проверка**: можно менять порядок, удалять/заменять фото, править описание, подтверждать статусы.

Без завершения проверки итоговый документ не создаётся.

При потере интернета фотографии, проект и уже готовые описания сохраняются локально и не удаляются.

## 8. Как получить PowerPoint и PDF

1. На экране проверки подтвердите все нужные фото.
2. Откройте экспорт. Приложение покажет счётчики:

   - Загружено / Использовано / Пропущено / Повторяющихся
   - Требуют проверки
   - Ошибки соответствия / PowerPoint / PDF

3. Если есть пропуски, повторы или несоответствия — экспорт останавливается.
4. Нажмите **Создать PowerPoint и PDF**.
5. Backend сгенерирует RU/EN PPTX на основе загруженного шаблона и визуально соответствующие PDF.
6. Файлы скачиваются в хранилище приложения и дублируются в `rin-repair-agent/output/<projectId>/` на компьютере с backend.

API-ключ **никогда** не попадает в PPTX, PDF или логи экспорта.

## Требования

- Android API 26+
- Kotlin, Jetpack Compose, Material 3
- CameraX, Photo Picker, Coroutines, Retrofit
- Android Keystore + Encrypted storage
- Node.js 18+ для backend
